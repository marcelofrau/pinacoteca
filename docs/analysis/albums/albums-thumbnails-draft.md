# Albums & Thumbnails (Picasa3)
- album.fen: Name, Date, Music (slideshow), Place, Description.
- constants.ui: alayout_thumbGutterX/Y, thumbsel_color1/color2 (thumbnail layout + selection).
- keywords/thumb, faceheaderpanel/set_thumbnail.
- eMenuLabelFolder::ID_ALBUM_SLIDESHOW, &View Slideshow.

## Behaviors
- Grid of thumbnails with gutters; selection highlight.
- Album metadata editing (name/date/location/description).
- Slideshow from album context.
- Folder/album grouping (Group in target strings).
